## 💫 Sobre Mim

Sou estudante de **Ciência da Computação** e desenvolvedor com foco em **Backend Java**, construindo APIs REST e aplicações orientadas a boas práticas de engenharia de software.

Meu principal ecossistema é **Java + Spring Boot**, trabalhando com **Spring Data JPA, Hibernate, PostgreSQL, Maven e Docker**. Busco desenvolver sistemas com código limpo, bem estruturado e preparados para manutenção e evolução.

Tenho interesse especial por **arquitetura de software, Clean Code, SOLID, DDD, Design Patterns, testes automatizados e desenvolvimento de sistemas escaláveis**.

Também estou expandindo meus conhecimentos em **Node.js, JavaScript, Python, Redis e Cloud**, buscando ampliar minha capacidade de construir soluções completas.

- 🔭 Atualmente desenvolvendo projetos com **Java e Spring Boot**
- 🌱 Aprofundando conhecimentos em **Backend, arquitetura de software, Docker, Redis e Cloud**
- 💬 Pergunte-me sobre **Java, Spring Boot, REST APIs, JPA/Hibernate e PostgreSQL**
- 🎯 Buscando oportunidades como **Estagiário / Desenvolvedor Backend Java**
- ⚡ Tenho facilidade para aprender novas tecnologias e estou sempre buscando evoluir tecnicamente
